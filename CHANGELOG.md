# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-14

### Added
- 📱 Mirror phone screen via scrcpy
- 📸 Take screenshots (saved to ~/Pictures/)
- 🎬 Record screen video (saved to ~/Movies/)
- 📵 Close mirror without quitting app
- 🔄 Auto-detect phone connection (polls every 5 seconds)
- 🔔 Notifications on phone connect/disconnect
- 🍎 Native macOS SwiftUI menu bar app with dynamic icons
- 🖥️ Cross-platform Rust system tray app (macOS, Windows, Linux)
- 📜 LaunchAgent for macOS auto-start
- 📜 Shell scripts for CLI usage
